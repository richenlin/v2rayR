# 设置项取舍：从 v2rayN 到 v2rayR

对照基线：[richenlin/v2rayN @ f07e3dc](https://github.com/richenlin/v2rayN/tree/f07e3dc41511a196f8ab563bcd2a16d1310ca8dd)。以该快照的桌面绑定、ViewModel 保存逻辑和配置模型为准。模型有字段，不代表桌面界面提供对应控件；也不表示每个平台或内核都支持同样的行为。

设置只在两种情况下交给用户：产品无法推断用户偏好，或用户掌握软件无法可靠获知的外部约束（公司网段、其他工具依赖的固定端口、订阅服务商要求等）。实现细节进入适配器或配置编译器，出现问题时给出诊断和恢复动作。按场景露出，不设置一个装满所有参数的「高级」页。

| 上游配置来源 | v2rayR 推荐默认 | 用户需要参与时，去哪里改 |
| --- | --- | --- |
| `OptionSettingViewModel`：登录自启、隐藏、托盘、统计 | 登录自启/自动连接关闭；托盘可用时关闭窗口留在托盘；不额外提供开机隐藏和托盘数量设置，最近节点固定最多 5 个；本地统计与实时速率按产品默认工作 | **启动与托盘**：登录时启动、启动后连接、关闭行为。清除历史属于诊断或数据操作 |
| `InItem`：本地端口、UDP、嗅探、监听、LAN 认证 | 仅回环；10808 优先，默认模式端口冲突时有限重试；UDP 与嗅探按能力启用，嗅探默认只匹配规则；不常驻第二端口 | **代理接入**：固定混合端口供第三方工具；开放 LAN 时条件展示账号密码，单独监听端口自动选择并展示实际地址；默认不开放 |
| `SystemProxyItem`：绕过、代理协议、PAC/脚本 | 系统代理按平台选择可用格式；默认绕过本地地址；写入前记录、失败或断开时按所有权恢复 | **代理接入**：是否绕过本地和额外例外。**连接**：选择系统代理或本地端口。PAC 有明确需求且通过平台验证后，再在接入模式中开放；不提供自定义脚本执行 |
| `RoutingSettingWindow` / `RoutingRuleDetailsWindow`：域名策略、规则与出口 | 内置绕过大陆预设；域名解析策略由内核和 DNS 方案决定 | **分流与 DNS**：选择规则预设。**连接**：规则 / 全局 / 直连。M3 给有工作网段、特定站点或出口需求的用户提供规则编辑器，能管理顺序、匹配条件及出口 |
| `DNSSettingWindow`：直连/远端/引导、hosts、FakeIP、AAAA、并行解析 | 默认自动；优先内置直连/代理 DNS 配置，引导地址由适配器确定；仅在接入与路由配套验证后启用 FakeIP。保留 AAAA；并行/缓存/双栈回退由适配器负责 | **分流与 DNS**：只有用户选自定义才显示两个 DoH 地址。需要域名重写时，在 M3 规则编辑器提供「本地映射」，系统 hosts 优先级需有行为测试；不暴露 FakeIP 地址池与每内核 DNS JSON |
| `TunModeItem`：栈、MTU、IPv6、路由、ICMP、DNS | 关闭；栈、MTU 和地址池由平台/内核策略决定；选取与现有网段不重叠的地址；IPv6 只有路由和 DNS 都通过验证才接管 | M4 **连接 → TUN**：是否启用、系统权限同意；有内网冲突时才提供排除网段。当前原型不展示可开启的 TUN |
| `CoreBasicItem` / `CoreTypeItem` / Mux、Fragment、mKCP、gRPC、Hysteria | 自动选经过验证的固定内核版本；默认不启用 Mux 或 Fragment；协议必需参数从节点读取；内核日志默认 warn 并脱敏 | 常规设置不列内核旋钮；缺内核时在连接错误处引导安装，短时调试在诊断启动并自动回退；保留节点格式要求的参数，不把它们提成全局设置 |
| `SubItem` / `SubEditWindow`：地址、名称、更新、UA、过滤、请求头、备用/转发 | 默认每 12 小时更新，优先直连失败再尝试当前代理；失败保留旧节点；只使用必要的默认请求头 | **订阅默认值**：全局周期。**订阅 → 编辑**：名称、地址变更（正式版需验证后再替换）、单条周期（继承/手动/固定间隔）。明确遇到兼容要求时再填 UA 或节点筛选；任意请求头、备用转发、转换服务暂缓 |
| `SpeedTestItem`：URL、超时、并发、UDP 目标 | 连通测试使用内置目标、5 秒超时、并发最多 8，并允许按资源压力收缩；下载测速仅手动开始 | **测速页**：测试方式、范围、停止；外部目标不可达时先说明测的是哪段链路，并提供重试/诊断，暂不列全局 URL、并发、超时 |
| `ThemeSettingView` / `UIItem`、`GlobalHotkeySettingWindow` | 主题和语言跟随系统；节点单击仅选中，明确点击才切换；字号随系统缩放；不默认注册会全局抢占的热键 | **外观**：主题、语言、字号。确有习惯需求时在 M2 提供快捷键绑定、冲突校验与清除 |
| `CheckUpdateView` / `BackupAndRestoreView`：渠道、资源、WebDAV | 稳定渠道，只检查和提示；应用、内核、规则独立校验与回退；本地导出默认排除秘密 | M4/M5 在**维护入口**提供检查更新、安装、备份和恢复动作；只有选择 WebDAV 后才填服务地址和凭据。预发布与自定义资源来源不列常规项 |

## 默认值与生效边界

- 对于系统代理、监听、DNS 和路由，草稿和实际运行态分别保存。默认端口和用户固定端口要用不同配置语义；固定端口冲突必须提示，不能静默换端口。涉及接管的配置改动先验证候选，失败保留或恢复旧会话。
- 新用户可按默认值导入并连接，设置页不是首启必经步骤。已知配置原因的失败，应直接链接到对应设置，如固定端口占用跳到代理接入，DNS 失败跳到分流与 DNS。
- 单条订阅为空时继承全局周期，填 0 时仅手动更新；全局变更不覆盖单条配置。节点名称筛选先提供关键词匹配；更复杂语法要有预览与明确的错误反馈。
- 原型只在本页会话记录草稿和已保存值。只有主题和字号即时预览；网络保存/重连均为模拟。未实现的功能通过本方案记录，不用无效控件占位。
