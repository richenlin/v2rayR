# 规则引擎审查整改记录

2026-11-12，针对当前未提交工作区复核。历史测试不作为当前文件状态的证明。

## 已整改

1. 普通会话只加载显式 Geo 引用资源，block_ads=false，不从旧 Geo/广告开关注入任何隐藏路由，保证 PAC 精简后只有默认直连。Geo 资源使用 ReferenceOnly，声明不附带动作。
2. 系统代理目标 bypass 为空；旧 pac 请求在会话入口和模式切换时归一为 system-proxy，不再启动 PAC 服务；移除 reload_active_pac 和旧自动规则资源收集函数。
3. rule_set_refs 接入实际会话，sing-box 的 cn 简写依据类型映射为 geosite-cn/geoip-cn，匹配本地 .srs 文件；路径和资源缺失明确报错。支持资源依然以本地已安装内容为限。
4. 保存与备份导入校验域名、CIDR，拒绝逗号/控制字符。Mihomo 生成前再次检查，已有数据库非法值也无法注入目标动作。
5. TUN 保留当前 OS 私网排除，每个 TUN 计划均明确提示接管范围限制；文档列明所有排除段。没有把私网规则标为已执行，没有未经安装态验证扩大特权接管范围。
6. 恢复用户请求策略与实际策略分离，避免 TUN 回退覆盖选择；平台已确定全局回退时不读取无关 PAC。

## 验证

- 最终工作区：336 passed、0 failed、6 ignored；无编译告警。
- 原生 real_connection 扩展测试通过：用真实 Xray/sing-box，开启旧 Geo/广告/绕过设置，以旧 pac 模式建立规则会话，检查真实生成配置无隐藏路由、接管目标 bypass 为空且不含 PAC URL。该测试使用替身系统代理，不等于原生 OS 接管验收。
